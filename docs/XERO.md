# Connect Xero for read-only reconciliation

Only a signed-in installation owner may configure Xero under Settings. Finance staff may read comparisons within their current native account scope; they cannot consent, map, read from the provider or link invoices. Buyer statements contain only that buyer's account. Agent credentials cannot use this connector.

Register an OAuth web application with Xero and register the exact installation origin followed by `/api/barrow/xero/callback`. Configure `XERO_CLIENT_ID` and `XERO_CLIENT_SECRET` as installation secrets, never browser settings. Keep the independent erasure journal configured before connecting. Hosted callbacks require HTTPS. Xero's demo organisation uses the same API as production; this adapter does not invent a sandbox host.

In Settings, enter the exact organisation tenant UUID, review separate provider custody, supply a reason and explicitly consent. Requested scopes are `offline_access`, `accounting.transactions.read`, `accounting.contacts.read` and `accounting.settings.read`. The callback binds the one-use state to the current owner session and verifies that Xero's connection list contains the reviewed organisation. No other tenant is selected automatically. Tokens are encrypted on the server, refreshed under a lease and excluded from archives. Interrupted rotation requires fresh consent. Disconnect ends independent local authority before attempting Xero disconnection; an unconfirmed provider result tells the owner to revoke the app in Xero.

Read and review contact, item, account and tax-code references. Contacts map to a current native account revision; item codes map to existing native SKUs. Account codes and tax types are reviewed reference labels, not verified tax or financial write authority. Source fingerprints detect changes when references are reread; changed native accounts or mappings invalidate a pending run. Read the current reference pages again when the provider configuration changes. Provider names, addresses and invoice narratives are not retained.

Start a dated invoice read. Each resume requests at most 50 existing authorised or paid receivable invoices, ordered by source identity. Reference snapshots that are not provider-paginated are bounded to 1,000 entries and locally paged; a larger snapshot is refused. A run is bounded to 100,000 invoice observations. Failed pages preserve the checkpoint and appear with their correlation and recovery action in diagnostics. Page-number reads do not provide a provider snapshot: upstream changes during pagination require a fresh reviewed read. Only complete reads establish comparisons, only on their actual supplier-calendar observation date. They establish no historical provider balance.

Review and link an existing native issued invoice with the same account, currency and total. A source invoice cannot be reused for another native invoice. Statements, their CSV and PDF, and finance reports show separately labelled Xero and QuickBooks rows, source IDs, observation time, correlation and differences for each currency. No currencies or provider balances are combined. Source edits, missing mappings and unmatched balances remain conflicts, with owned follow-up tasks until source-confirmed matching or an attributed human acknowledgment. No connector observation changes native opening or closing balances, applies a payment, issues a credit or changes an issued document.

Scoped JSON and CSV exports include `xeroobservations`. Archived observations remain financial history; restored reads and connection authority are inactive. Latest observation and provider update instants extend the exact seven-calendar-year financial floor. Owner-reviewed erasure removes live contact mappings and independently fences their reuse after restore while preserving required financial history. Xero holds separate copies; Barrow sends no provider deletion and claims none.

The live net-terms order, Xero payment allocation and returned native payment synchronization are not implemented by this read foundation. Financial writes, full finance delegation and the complete live sandbox receipt remain INT-003 work. Held client keys do not establish tenant authority or callback registration.
